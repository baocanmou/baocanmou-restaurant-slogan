# 隐私说明 / Privacy

本仓库包含可阅读的 Skill、文档、图片和本地 Python 工具。没有服务器、登录、API Key、遥测、自动联网、浏览器读取、MCP 服务或上传功能。安装脚本只复制本地文件，结构检查只读取本地 JSON 与来源目录。

使用 AI 助手时，输入可能按**宿主助手**的数据政策处理，本项目无法控制该政策。不要把客户秘密、个人信息、未授权素材或凭据放进公开 Issues、PR 和示范。公开搜索近似表达会把句子发送给搜索服务，应先确认可公开。

GitHub 按其政策处理账户、访问、Issues 和 Actions 等数据。README 不含自建追踪像素或分析脚本。

This repository contains readable Skill instructions, documentation, images and local Python tools. It has no server, login, API key, telemetry, automatic network call, browser reading, MCP service or upload feature. The installer copies local files; the checker reads local JSON and the source catalog.

Your AI assistant may process input under **its own data policies**, which this project does not control. Keep client secrets, personal data, unauthorized assets and credentials out of public Issues, PRs and examples. A public similarity search sends the wording to a search provider; obtain permission before exposing confidential copy.

GitHub handles platform activity under its own policies. The README includes no custom tracking pixel or analytics script.
