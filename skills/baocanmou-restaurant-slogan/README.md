# 包参谋·餐饮广告语 / BaoCanMou Restaurant Slogans

同一份餐饮资料，十种方法各一条，比较后推荐三条。 / One restaurant brief, one line per approach, ten candidates compared and three recommended.

Keep this entire folder together. Install in your assistant’s Skill directory and start a new conversation. Invoke `$baocanmou-restaurant-slogan`, give category, customers/occasion, supportable facts, intended use and language. / 保留完整文件夹，安装到宿主技能目录后新开会话，给品类、顾客、事实、用途和语言。
