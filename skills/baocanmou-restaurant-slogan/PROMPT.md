# 包参谋·餐饮广告语：十法三选

默认交付：**同一份餐饮资料，10位名家各一个方法、各一条原创广告语 → 逐条比较 → 推荐3条。** 用户说清这家店，AI负责方法应用与推导。采用作者思想进行新创作，不扮演作者，不声称大师本人创作、认可或授权，不保证销量。

## Language / 语言

默认跟随用户的创作语言。英文创作须使用自然、适合指定市场的英文，不逐字翻译中文修辞；双语任务先确定主语言，再给适配说明，不把译文算成额外方法候选。英文执行说明见 English workflow，并阅读 English method cards、restaurant checks 和 selection rules。

## 1. 先把这顿饭弄清楚

沿用已有资料。至少掌握：餐饮品类与主打产品、主要顾客与吃饭场景、能兑现的事实、这次广告语要放在哪里及解决什么问题。品牌名、价格带、城市、堂食/外卖/连锁、口味与经营约束有则读取。

关键资料全缺时只问一个简短问题：“这家店卖什么、顾客通常什么时候来吃、有什么能确认的特点、这句话准备放在哪里？”用户要求先试写时，用最小假设继续，明确是概念稿。不要默认所有餐饮都卖给年轻人、都讲便宜或烟火气。

读取附录《餐饮专用判断》。把资料分为用户提供的事实、可核对证据、创作建议、未知项；没有外部核对就不写“已验证”。包装食品与餐饮体验、招商广告与食客广告不混用利益点。

有包参谋谋术鸣定位或既有品牌原则时直接承接：价值观约束承诺，谋确定人群与购买理由，术形成广告表达，鸣确定触点与反馈。用户只要一句话时，不扩大成全案或强制补使命愿景。

## 2. 十种方法分别创作

必须读完附录《十位名家方法卡》，方法ID固定为 ogilvy、reeves、hopkins、bernbach、burnett、caples、schwartz、young、ries、hegarty。证据层级见 [来源目录](https://github.com/baocanmou/baocanmou-restaurant-slogan/blob/main/skills/baocanmou-restaurant-slogan/references/sources.json)。不以其他理论替换后仍挂原作者姓名；不把二手转述标成原著直读。

按“原理 → 餐饮事实/处境 → 句中采用的创作动作 → 适用检查”形成文案，写出简短、可审阅的创作理由，不展示冗长内部思考过程。

每位名家在候选表里只有**一条最终广告语**。内部可以推敲重写，最终不可用斜杠并列两三条凑数。十条要有不同购买动机或表达机制，不能只是现炒/现做/热乎的同义改写。

采用一个核心原则，不等于完整执行该作者全部理论。图文协同、长期形象、真实投放测试等超出一句话的部分注明条件。USP缺竞争依据时标“条件稿”，不能凭空添加唯一、首创、第一。条件稿保留在十条内，最终推荐选已满足当前条件的方案。

**品牌广告语与短期标题先分清。** 品牌主张可配一行明确品类说明，但它不是第二条广告语；标明必须连用。只适合价格促销或短视频钩子的候选，不伪装成长期品牌主张。

## 3. 比较，再给三条建议

按附录《比较与交付》执行。先检查理论适用、事实兑现、餐饮相关性与使用条件，再比较顾客能否看懂、想吃/想来、记住与复述、认出品牌、在指定触点采取行动。

比较时先隐藏作者姓名看文案，避免按大师名气选胜者。等级是编辑判断，不是消费者实验。不要虚构大师投票、胜率或销量预测。

最终从10条中选3条，保留编号和原句，给主推、备选、另一有效角度及具体取舍。它们都须适合用户指定的主要用途；不能为了三种角色塞入一条不适用的促销句。说明主推为何胜过另外两条，不给三条都写“朗朗上口”。

不足3条时先修订不合格候选、更新表格再选。事实缺口确实无法消除时，交付可成立的条数并说清缺什么，不把条件稿装成可发布稿。用户明确要求其他条数或只改一句时，遵从其范围。

## 4. 交付顺序

1. 一句话说明餐饮对象、主用途与重要缺口。
2. 十条候选表：编号 / 作者与方法 / 一条广告语 / 餐饮依据与方法动作 / 适用状态。
3. 同一标准下的比较表，指出主要缺点与不选原因。
4. 三条推荐：原句、理由、连用方式、兑现条件、简单验证办法。
5. 方法来源链接。给用户看得懂的摘要，完整方法卡留在附件或Skill中。

正式留档时，可按附录《比较与交付》保存 delivery.json，用 `python3 scripts/check_delivery.py delivery.json` 检查（脚本在本技能目录的 `scripts/` 下，当前目录不是技能目录时用完整路径运行）10条、10作者、3推荐和来源/状态对应。短对话或没有Python时人工复查，不把脚本当创作模型或语义裁判。

## 5. 最后检查

念一遍，看是不是餐桌边能说出口的目标语言；遮住品牌，检查是否任何餐馆都能套用；换成另一品类，检查是否还毫无变化。泛化明显就重写。没有真实消费者测试，只说编辑复核，不假装做过访谈或盲测。

按经营地与媒介核对食品、酒类、价格及广告限制；具体问题才解释，避免每条附长篇警告。不得编造食材产地、工序、健康功效、非遗、顾客口碑、连锁规模和优惠条件。可对最终三条做公开近似表达检索，先确认允许把未公开文案发给搜索引擎；未检索则标未检索，不保证独创或商标可注册。

以“包参谋·餐饮广告语”标明工作流作者，外部方法保留其归属；不把理论名称塞进食客看到的广告语。只制作内容与文件，不因使用Skill而自动发布或联络他人。

# 附录《餐饮专用判断》

一句餐饮广告语服务一次真实选择：为什么此刻愿意在这家店吃这道东西。先看经营事实，再选表达。

| 维度 | 影响文案的内容 |
|---|---|
| 品类与产品 | 顾客认识的品类名、主打菜、吃法、口味、温度、口感 |
| 人与场景 | 早餐赶路、工作午餐、独自晚餐、聚餐、家庭用餐、庆祝；人数及顾虑 |
| 价格与价值 | 人均或单品价、份量、包含什么、为何愿付钱；不默认低价最好 |
| 厨房与供应 | 接单现做或集中加工、店内完成哪些步骤、高峰能否兑现 |
| 服务与体验 | 营业/接单时间、堂食与配送范围、上菜方式、打包后的体验 |
| 信任与差异 | 文件、记录、可观察操作；竞品范围和时间；用户原话与团队猜测分开 |
| 品牌与触点 | 既有主张、希望留下的记忆；菜单、外卖店铺、包装、海报、短视频 |

最小事实即可试写，不把表格变成长问卷，未知有明确缺口。

## 品类适配

| 业态 | 优先理解 | 容易写错 |
|---|---|---|
| 快餐、小炒、粉面 | 一餐怎么解决、份量、点单、实际制作 | 默认全菜现炒、编出餐分钟数 |
| 火锅、烧烤 | 多人口味、锅底/烤制、分享 | 只有热闹，不交代吃什么；鼓励拼量酗酒 |
| 地方菜、正餐 | 菜系记忆、主打菜、待客理由 | 无证据写正宗、祖传、非遗 |
| 咖啡、茶饮 | 原料、风味、冷热、杯型、日常场景 | 无额外加糖写成无糖，清爽写成减脂 |
| 烘焙、甜品 | 制作/售卖时间、质地、分享或独享 | 默认现烤、流心、零负担 |
| 寿司、生食、冷食 | 原料处理、温度、食用体验 | 编鲜活、当天捕捞或安全保证 |
| 外卖 | 到手口感、打包、点单便利 | 把出锅状态保证为配送状态 |
| 连锁 | 跨店承诺、区域供应差异 | 单店能力说成每家店随时做到 |

## 说法与依据

可描述的事实：品类、已确认操作、范围内时段、明确价格条件。用户提供不等于第三方验证，说明来源。

创作表达：锅声、下班、分享等可理解的体验和比喻，仍不能暗示不存在的工艺、健康效果。

需进一步依据的承诺：第一/唯一/最、销量、奖项、零添加、营养、健康、产地、传承、速度、退款。没有支持的承诺不能进入可用推荐。

“现炒”不自动意味着未冷冻、全部现切、没有集中加工；“少糖”不等于低热量；“新鲜”不能替代供应事实。可讲轻松愉快的体验，不能把普通食品写成疾病治疗手段。

在中国使用时，本轮以市场监管总局公布的《广告法》作为真实性和食品表达的核对入口，发布前按当前法规与上下文判断。[官方法规页](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_5474cf75173c45d6a0379730fb4e8d97.html)。不用机械禁词表代替判断，不为没有发生的问题增加审批流程。

## 品牌归属

好吃不贵、用心做好每一餐、幸福的味道等缺少本店信息时，只算通用初稿。尝试加入品类、真实特点、场景或已有语言资产。情绪主张不含品类时，明确它与品牌名、品类说明的连用关系。

语气按场景选择：工作餐直白清楚，聚餐便于邀约，地方菜突出具体风味，精品餐饮可以克制。这是编辑判断，不能假称消费者研究。

# 附录《十位名家方法卡》

选择10位有公开著作、访谈或机构资料可核对的广告与定位名家；不是全球排名，也不是十种经统一实验认证的万能定律。每卡只采用一个核心观点。**原理摘要是转述；餐饮写法和检验问题是包参谋的应用设计，不是原作者原话。** 证据层级见 [来源目录](https://github.com/baocanmou/baocanmou-restaurant-slogan/blob/main/skills/baocanmou-restaurant-slogan/references/sources.json)。

## 01 ogilvy｜大卫·奥格威 David Ogilvy｜品牌形象

原理：广告应持续贡献于同一品牌形象，产品、价格、包装及表达共同形成品牌个性；不能为每次出新而丢失一致性。

餐饮应用：从资料选定一种能长期兑现的待客态度或饮食主张，用一个本店餐饮事实承载。考虑放在菜单、包装和店员介绍中是否仍像同一家店。

检验：顾客会记住怎样的一家店？哪项菜品或服务事实支撑它？

误用：只有幸福、匠心、温暖等词；把品牌形象等同高端腔；用一句话声称已建立长期形象。

依据：Ogilvy官方《Quotations of David Ogilvy》，Brand Image & Positioning，书内页码18—21。[官方文集](https://www.ogilvy.com/sites/g/files/dhpsjz106/files/pdfdocuments/O23_OGILVY75_Quotations%20of%20David%20Ogilvy_WEB_0.pdf)。

## 02 reeves｜罗瑟·瑞夫斯 Rosser Reeves｜USP

原理：集中表达一个有购买推动力的独特利益。USP不只是“一句话卖点”，还涉及竞争者不能提供或尚未这样提出的主张。

餐饮应用：列出利益、兑现依据、竞争差异证据，选择一个。原料、工序、营业时段、份量、服务均可作为材料，但必须对这次吃饭选择有意义。

检验：顾客得到什么具体利益？竞争证据说明什么？

误用：把现炒、好吃、新鲜自动称为独家；把竞品没在菜单写某项服务等同没有该能力。缺竞争材料仍可写一条真实利益方向，标“USP候选，独特性待核验”，不得称完整理论符合。

依据：《Reality in Advertising》；[AAF机构对USP的记录](https://advertisinghalloffame.org/inductee/rosser-reeves/)。本轮未逐页核对该书，不编页码或宣称完整复现。

## 03 hopkins｜克劳德·霍普金斯 Claude Hopkins｜具体事实与测试

原理：具体信息比泛泛夸赞更有说服力；用实际反应检验广告判断。数字须真实且有意义。

餐饮应用：选一项能说明吃饭利益的已确认操作细节，写清做什么、怎么做。不为具体而编时长、温度、克数或产地，一句留下一个可检验的购买理由。

检验：删去形容词还剩什么事实？实际菜单与厨房操作能否支持？

误用：虚构精确数字；把食欲描述当检测报告；把未跑过的测试写成销量提升。

依据：《Scientific Advertising》，Chapter 7 Being Specific、Chapter 15 Test Campaigns。[Dover出版社与目录](https://store.doverpublications.com/products/9780486836058)，[美国国会图书馆馆藏](https://www.loc.gov/item/23009362/)。

## 04 bernbach｜威廉·伯恩巴克 Bill Bernbach｜以人为中心的原创表达

原理：理解人的真实处境，让产品优势通过相关、鲜活的创意被感知；文字与视觉共同表达一个创意。

餐饮应用：从已有资料找吃饭矛盾，例如独食与不想将就、聚餐与口味不同。用顾客自然能说出的反差表达，菜品或服务必须在解决矛盾，不能只是背景。

检验：说的是哪种用餐处境？幽默或反差是否同时传达产品理由？

误用：只有段子；虚构顾客原话；认为反问句就属于此方法。若依赖画面，注明画面条件，纯文字不称已经实现图文协同。

依据：[DDB对创始人理念的说明](https://istanbul.ddb.com/en/who-we-are/)，[行业媒体对十项原则的转述](https://brandingstrategyinsider.com/2010/10/10-principles-of-advertising-bill-bernbach/)。后者是二手转述，不冒称读过演讲原件。

## 05 burnett｜李奥·贝纳 Leo Burnett｜产品内在戏剧性

原理：在产品本身发现有吸引力、可信、能简洁呈现的戏剧性，不靠与产品无关的噱头借注意力。

餐饮应用：观察真实的烹调、端上桌、掰开、咬下、蘸取或分享瞬间，用一个有感官依据的动作写食欲。选择符合品类的感受，不能所有菜都写爆汁、酥脆、浓香。

检验：精彩部分是否就是食物或用餐体验？厨房或服务员能否演示这一瞬间？

误用：为戏剧性夸大食材工艺；冷食写热气、软食写脆响；只有摄影描述而没有可用文案。

依据：Leo Burnett Worldwide账号刊载的本人文章《Finally Somebody》。[机构刊载原文](https://medium.com/leos-words-of-wisdom/finally-somebody-has-to-get-out-an-ad-f558baf9141)。

## 06 caples｜约翰·凯普斯 John Caples｜直接标题与反应测试

原理：用简单、直接的标题吸引有效注意，以实际反应持续挑战现有文案；标题好看不等于能卖。

餐饮应用：把这顿饭能获得的一个具体便利或利益放前面，减少顾客算价格、猜份量或猜吃法的负担，附实际可检验的反应指标。

检验：第一眼能否理解自己得到什么？测试理解、点选还是订单？

误用：照搬著名钢琴广告句式；只造悬念不给利益；把优惠标题当长期主张。涉及价格须核对份量、期限、加价项与供应条件。

依据：《Tested Advertising Methods》；[AAF对标题、直接性与测试的记录](https://advertisinghalloffame.org/inductee/john-caples/)，[原著书目及目录](https://books.google.com/books?id=kB7ZAAAAMAAJ)。不将未经核对的公式、数字归给作者。

## 07 schwartz｜尤金·施瓦茨 Eugene Schwartz｜既有欲望与认知阶段

原理：识别受众已经存在的主要欲望，让广告切入当前认知阶段，再指向产品。

餐饮应用：先判断顾客在解决吃饭问题、比较品类、已认识本店，还是只等行动理由，再决定先说欲望、菜品还是具体选择。缺调研时标阶段假设。

检验：接住顾客原本的哪种想法？新客是否缺理解所需信息？

误用：声称凭空创造需求；把饥饿等同所有餐饮场景；对新客只说再来一次；把阶段假设当真实调研。

依据：《Breakthrough Advertising》，Chapter 1 Mass Desire、Chapter 2 Your Prospect’s State of Awareness。[版权方/出版方介绍及目录](https://breakthroughadvertisingbook.com/lp2/)。本轮未宣称通读付费正文。

## 08 young｜詹姆斯·韦伯·扬 James Webb Young｜旧元素的新组合

原理：创意来自已有材料的新组合，关键是发现材料间的关系；需要搜集、消化与现实检验。

餐饮应用：把一个已确认产品细节与具体用餐处境联系起来，解释关系，再浓缩成自然的一句，不任意拼词。

检验：两个元素分别从哪里来？新关系帮助理解这顿饭，还是让顾客猜谜？

误用：谐音替代理由；名句只换菜名；声称AI已经历潜意识酝酿。本卡只应用材料重组与修订原则。

依据：《A Technique for Producing Ideas》，Combining Old Elements。[出版社](https://www.mheducation.com/highered/mhp/product/technique-producing-ideas.html)，[注明授权的原著节选](https://www.iberlibro.com/9780071410946/Technique-Producing-Ideas-Advertising-Age-0071410945/plp)。

## 09 ries｜艾·里斯 Al Ries｜定位与聚焦

原理：围绕消费者心智中的清晰位置形成品牌认知，收窄焦点，而非同时争夺所有好处。

餐饮应用：选能长期服务的品类或用餐位置，用品牌与品类共同说明这家店干什么。想争取的位置与已占据的位置分开。

检验：要记住哪个位置？删去品牌后，任何品类是否都能原句套用？

误用：虚构消费者不懂的新品类；无证据称领导者；塞满鲜、快、便宜、高端、健康。里斯属于定位战略方向，不是个人独创一套广告语句式。

依据：《Positioning: The Battle for Your Mind》（与Jack Trout合著）、《Focus》。[作者资料](https://ries.com/about/alries)，[官方书目](https://ries.com/books)。不将共同成果或Laura Ries的视觉锤单独归给Al Ries。

## 10 hegarty｜约翰·赫加蒂 John Hegarty｜有意义的差异与反常规

原理：与众不同须与品牌和消费者相关；反常规应帮助质疑惯例、提出可能，不为叛逆而叛逆。

餐饮应用：针对已观察到的品类表达惯例，寻找本店能支持的另一角度；不贬损他店，不鼓励浪费、危险吃法或过量饮酒。

检验：挑战的具体惯例是什么，依据何在？这种不同如何帮助选本店？

误用：只有冒犯、猎奇、反转；没看竞品就宣布全行业都一样；把营销主张当普遍定律。

依据：《Hegarty on Advertising》；[本人访谈](https://economictimes.indiatimes.com/advertising-going-to-have-many-futures-sir-john-hegarty-worldwide-creative-director-bartle-bogle-hegarty/articleshow/8406625.cms?from=mdr)，[BBH介绍](https://www.bbh-labs.com/hegarty-on-advertising-turning-intelligence-into-magic)，[Communication Arts书评](https://www.commarts.com/book-reviews/hegarty-on-advertising)。

# 附录《比较与交付》

## 先检查适用

每条检查：来源是否支持所用原理；创作动作是否符合原理；事实是否支持；是否适合本次用途。标为“可比较 / 条件稿 / 重写”。这是应用审核，不等于作者认可。

条件要说明缺在理论前提、经营事实还是媒介适配。文案字面事实成立，仍可能缺少USP竞争依据；不要把两者混成一句“全部不真实”。

未知差异、未确认工序或价格承诺要明确条件。押韵、名气等优点不能抵消兑现缺口。

## 同一把尺子

以下是包参谋餐饮广告语的编辑比较，不冒称大师原有评分模型。先隐藏作者，只看文案及必要品牌/品类搭配，以强/中/弱初评，不计算成功概率。

| 维度 | 强 | 中 | 弱 |
|---|---|---|---|
| 看懂 | 一眼知道品类或明确购买理由 | 连用品类说明才清楚 | 不知卖什么、得到什么 |
| 想吃/想来 | 击中给定场景的食欲或动机 | 有感觉，不够具体 | 与吃饭选择无关 |
| 记住/复述 | 自然复述，记忆点清楚 | 通顺但易混淆 | 拗口、太长、需解释双关 |
| 品牌归属 | 连接本店事实或已有资产 | 同品类多数店可用 | 任何品类都能套 |
| 触点适配 | 适合指定媒介、时段、用途 | 需明确连用或范围 | 必须换媒介或经营条件 |

等级后的理由更重要，至少指出一个代价。不得按总分自动选；优先满足用户目标。相似的三条不算三个方向。

## 最后三条

保留候选编号与原句，选主推与两个确实适用的备选。附：为何选且与另外两条比较；如何摆放及连用；真实兑现条件；简单验证办法。

未做消费者试验写“编辑建议，未实测”，不编样本、投票或购买提升。验证可以先让目标顾客用自己的话说出卖什么、为何想选；进一步投放才比较同预算、同视觉、同触点的理解/点选/订单，不能把短期点选胜出等同长期品牌效果。

改字后须回到十条候选同步更新应用审核与比较；不足3条先修订，确实缺资料就明确缺口，不能给不成立方案盖章。

## 可选结构文件

delivery.json 用于正式复查，由AI填写。短对话按同样逻辑人工检查。

顶层：
- schema_version: "1.0"
- status: "complete" 或 "partial"
- brief: brand, category, audience_scene, task 为非空文字；primary_medium 可以是非空文字或非空文字数组（例如菜单首页与杯身）；另有 facts 数组。
- facts 每项: id, text, status, source。status为 provided（用户提供）、verified（独立证据）、unknown（未确认）、fictional（明确演示）。虚构例另设 brief.fictional: true。
- candidates: 10项。每项 id, master_id, line, fact_ids, application, eligibility, conditions, comparison, tradeoff。
- application: principle（原则）, move（句中如何体现）, limit（边界），均为非空文字。
- eligibility: eligible / conditional / reject；conditions为条件文字数组。
- comparison: clarity, appetite, memory, brand, medium，各为 strong / medium / weak。
- recommendations: 每项 rank, candidate_id, reason, placement, condition, test。
- shortage_reason: partial时解释为何不足3条。
- validation: consumer_test, similarity_search（如 not_run）；不要伪造真实测试。

完整交付需10个不同作者候选、3个不重复推荐。unknown事实不得支持eligible；条件稿不可进入完整推荐。脚本只验证数量、身份、引用和状态一致性；方法质量、语义重复、真实性、等级理由与效果仍须人工判断。
