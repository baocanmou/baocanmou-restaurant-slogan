# 安全与敏感资料 / Security

不要在公开 Issue 粘贴凭据、客户原始资料或敏感漏洞细节。若 GitHub 私密漏洞报告可用，请使用仓库 Security 报告入口；否则先提交不含敏感内容的简短 Issue，请维护者提供私密方式。

Do not post credentials, client source material or sensitive vulnerability details publicly. Use GitHub private vulnerability reporting if available. Otherwise open a minimal, non-sensitive issue requesting a private channel.

本项目无联网服务或依赖安装器。运行前应阅读代码；下载后可核对 Release 哈希。SHA-256 证明文件一致性，不等于安全认证。本项目无正式安全响应时限或审计认证。

There is no network service or dependency installer. Read code before running it and compare release hashes. SHA-256 verifies consistency, not security certification. No formal response SLA or security certification is claimed.
